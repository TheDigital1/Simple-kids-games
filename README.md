# Simple Kids Games

Small, self-contained browser games for kids. Each game is a single HTML file — open it in a browser, no install or build step needed.

## Games

| Game | Description |
| --- | --- |
| [Spark Count](spark-count/index.html) | Tap the screen to count up: each tap bursts into sparks that gather into the next number, which is read aloud. A frog in a boat floats on the water and can be dragged and tossed for a splash. |
