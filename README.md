# Simple Kids Games

Small, self-contained browser games for kids. Each game is a single HTML file — open it in a browser, no install or build step needed.

**[▶ Play Spark Count now](https://thedigital1.github.io/Simple-kids-games/spark-count/)** · **[▶ Play Bubble Pop now](https://thedigital1.github.io/Simple-kids-games/bubble-pop/)**

## Games

| Game | Play | Description |
| --- | --- | --- |
| Spark Count | [▶ Play now](https://thedigital1.github.io/Simple-kids-games/spark-count/) | Tap the screen to count up: each tap bursts into sparks that gather into the next number, which is read aloud. A frog in a boat floats on the water and can be dragged and tossed for a splash. |
| Bubble Pop | [▶ Play now](https://thedigital1.github.io/Simple-kids-games/bubble-pop/) | A bunny blows bubbles: first 1, then 4, then 8 at a time. Pop as many as you can in one minute! Bubbles drift on the breeze, and popping one pushes its neighbors away. |

## Install as an app

Each game can be installed on a phone, tablet or computer and played offline. Open the game with its **Play now** link, then:

- **iPhone / iPad (Safari):** tap Share → **Add to Home Screen**.
- **Android (Chrome):** tap ⋮ → **Install app** (or **Add to Home screen**).
- **Computer (Chrome / Edge):** click the install icon at the right end of the address bar.

When a game's files change, bump `VERSION` in that game's `sw.js` so installed copies update.
