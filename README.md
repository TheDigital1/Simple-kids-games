# Simple Kids Games

Small, self-contained browser games for kids. Each game is a single HTML file — open it in a browser, no install or build step needed.

## Games

| Game | Description |
| --- | --- |
| [Spark Count](spark-count/index.html) | Tap the screen to count up: each tap bursts into sparks that gather into the next number, which is read aloud. A frog in a boat floats on the water and can be dragged and tossed for a splash. |

## Install as an app

Each game can be installed on a phone, tablet or computer and played offline. Open the game's page (it has to be served over https, e.g. GitHub Pages), then:

- **iPhone / iPad (Safari):** tap Share → **Add to Home Screen**.
- **Android (Chrome):** tap ⋮ → **Install app** (or **Add to Home screen**).
- **Computer (Chrome / Edge):** click the install icon at the right end of the address bar.

When a game's files change, bump `VERSION` in that game's `sw.js` so installed copies update.
